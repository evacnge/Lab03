# Lab03
Lab Summary

In this lab, we learned about Geometric and Intensity Transformations in image processing. We applied different geometric transformations such as scaling, non-uniform scaling, rotation, and shearing to understand how they change the size, shape, and orientation of an image. We also learned intensity transformations, including Negative, Log, and Power-law (Gamma) transformations, which help us modify and improve the intensity levels of an image. Overall, this lab helped us understand how different image transformations can be applied using Python, PIL, NumPy, and image processing techniques.
